# Pins for the RKNN converter on an x86_64 Linux host (calbredge convert --framework rknn),
# from the validated environment on that host: Python 3.12.3, rknn-toolkit2 2.3.2 (2026-10).
#
# Install in a fresh venv, from a clone, with PyTorch's CPU-only index as an extra index:
#
#   python3 -m venv ~/calbredge-venv
#   ~/calbredge-venv/bin/pip install -c constraints/rknn-convert-x86_64-py312.txt \
#       --extra-index-url https://download.pytorch.org/whl/cpu \
#       rknn-toolkit2 ./protocol "./agent[rknn-convert]"
#
# torch is the CPU-only build (2.4.0+cpu, from that index): rknn-toolkit2 2.3.2 needs
# torch<=2.4.0, and conversion uses no GPU. Without the index, pip installs the CUDA build,
# about 2.8 GB of downloads and 5.6 GB on disk with its nvidia-* packages and triton, against
# about 400 MB of downloads and 1.6 GB on disk with the CPU build.
#
# onnx is exactly 1.18.0: rknn-toolkit2 2.3.2's load_onnx breaks on newer releases.
# setuptools is below 81: rknn-toolkit2 imports pkg_resources, which setuptools 81 removed.
# protobuf 4.25.4 works with the default implementation, so no
# PROTOCOL_BUFFERS_PYTHON_IMPLEMENTATION is needed.
#
# calbredge and calbredge-protocol aren't pinned here: they install from the clone.
#
# Every line is a package that install resolves: rknn-toolkit2's requirements and theirs
# (torch, onnx, onnxruntime, opencv-python, scipy, ...), and calbredge's (with the
# rknn-convert extra).
