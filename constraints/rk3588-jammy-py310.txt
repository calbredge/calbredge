# Pins for a Calbredge install on an RK3588 board (Orange Pi 5 Plus, vendor Ubuntu Jammy,
# Python 3.10), from the validated environment on that board (2026-10).
#
# Use with an isolated venv, never --system-site-packages: a board with pip --user packages
# would load those ahead of the venv's. Everything here installs from wheels, so the board's
# stock pip is enough and nothing is compiled:
#
#   python3 -m venv ~/calbredge-venv
#   ~/calbredge-venv/bin/pip install -c constraints/rk3588-jammy-py310.txt \
#       --find-links <kit> "calbredge[rk3588]==<version>"
#
# calbredge and calbredge-protocol aren't pinned here: they come from the release kit, and
# calbredge pins its own protocol exactly.
#
# rknn-toolkit-lite2 is the Python binding only. The runtime library it loads,
# librknnrt.so, is not a pip package: `calbredge doctor` checks that it is installed and
# matches this binding's version.
#
# Every line is a package the kit's install resolves: calbredge's own requirements,
# rknn-toolkit-lite2's (numpy, psutil, ruamel.yaml) and theirs.
